设计说明 · DESIGN NOTES

  1. 纸感票根手账语言：暖白期刊纸（#F7F2E7）+ 手绘细线 + 大量留白 + 胶带拼贴，叠加复古票根隐喻——打孔线 / 副券 / 条码 / 编号 / 印章，参考北港茶小程序与两张复古票根。
  2. 单一强调色 + 语义色：茶绿 #445C38 全站唯一强调（可交互 / 有票）；朱砂 = 热卖·回流·售罄（#A23B2E），琥珀 = 额度提醒（#8A6A1B）。
  3. 形状规则：纸 = 裁纸直角 2px（--r），功能 = 药丸 999px（--r-pill）；阴影一律暖墨调 rgba(42,38,32,.07)，禁纯黑投影。
  4. 零自定义字体：全站系统默认字体，无 font-family 声明；标题一律单行（white-space:nowrap），折行视为排版事故。
  5. WCAG AA 19 项全过：纸面 #F7F2E7 上 ink 13.5:1 / accent 6.6:1 / stamp 5.9:1 / warn 4.5:1 等，由 tools/check_palette.py 校验。
